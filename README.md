# TripAdvisor-Clone
A modern, responsive travel website UI inspired by platforms like Tripadvisor.
Built using HTML + CSS, focusing on clean design, responsiveness, and user experience.

🚀 Features
✅ Sticky Navbar (scroll with page)
✅ Responsive Design (Mobile + Tablet + Desktop)
✅ Search Bar UI
✅ Tabs with Icons (Radio-based navigation)
✅ “Plan with AI” Button (Glow effect)
✅ Social Media Icons (Font Awesome)
✅ Clean Layout with Flexbox & Grid

🛠️ Technologies Used
HTML5
CSS3 (Flexbox + Grid + Media Queries)
Font Awesome (for icons)
Google Fonts (Inter font)
